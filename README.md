# AlgoViz · C++ 算法可视化

一个**纯静态**的教学网页：左边是 C++ 参考代码，右边同步演示图与存储结构的每一步变化。
不需要后端、不需要数据库、不用登录，双击就能用，也能直接发布成公网链接。

## 直接打开

双击 `index.html`。不需要服务器、不需要安装任何东西。

## 已经实现

左侧目录分六段：**基础 / 动态规划 / 数据结构 / 字符串 / 图论基础 / 进阶**，共 31 个课时。

### 基础

| 模块 | 内容 |
|---|---|
| 冒泡排序 | 相邻比较、交换、每轮末尾就位、整轮无交换提前结束 |
| 二分查找 | `lo / mid / hi` 指针、候选区间逐次减半、命中高亮 |
| 快速排序 | 基准、`i / j` 双指针划分、递归调用栈、基准归位 |
| 归并排序 | 递归分治、`tmp[]` 临时数组逐格写入、写回原数组 |
| 前缀和 | `pre[i] = pre[i-1] + a[i]`，区间查询变成两个数相减 |
| 差分 | 区间修改只动两个位置，再做前缀和还原 |

### 动态规划

| 模块 | 内容 |
|---|---|
| 01 背包 | 二维表逐格填写、依赖 `i-1` 行、`max` 取舍、答案 `dp[n][W]` |
| 完全背包 | 同样的表，只把依赖改成同一行 `i`，答案从 10 变 12 |
| 记忆化搜索 | 调用栈 + memo 表，命中缓存时不再递归 |
| 区间 DP · 石子合并 | 按区间长度从小到大填表，枚举切点，依赖两个子区间 |

### 数据结构

| 模块 | 内容 |
|---|---|
| 单调栈 | 栈内值单调递减、`a[i]` 更大时弹栈、`ans[i]` 找左边第一个更大元素 |
| 堆 | 数组 ↔ 完全二叉树双视图，插入后一路和父节点交换 `sift-up` |
| 树状数组 | `lowbit` 建树、父节点 = `i + lowbit(i)`、查询沿 `i - lowbit(i)` 跳 |
| 线段树 | 区间树形视图、建树自底向上、查询时整段命中 / 部分重叠 |
| Trie 字典树 | 按字符分层、共用前缀只存一份、`end` 标记单词结尾 |

### 字符串

| 模块 | 内容 |
|---|---|
| KMP | `nxt` 逐位构造、失配回退、模式串随文本滑动、命中位置高亮 |

### 图论基础

| 模块 | 内容 |
|---|---|
| 存图 · 邻接表 | 每条边如何变成 2 条有向邻接边 |
| 存图 · 邻接矩阵 | 对称位置赋值、空间代价 |
| 存图 · 链式前向星 | `head / to / wt / nxt` 的链表插入过程 |
| DFS | 调用栈、回溯、访问顺序 |
| BFS | 队列、`dist` 逐层扩散、访问顺序 |
| 拓扑排序 | 有向图箭头、入度递减、入队顺序、判环 |
| 二分图判定 | BFS 逐层染反色，相邻同色即判定失败，节点按两组上色 |

### 进阶

| 模块 | 内容 |
|---|---|
| Dijkstra | `dist` 松弛、小根堆进出、过期元素跳过、操作计数 |
| Bellman-Ford | 带负权的有向图，每轮把所有边扫一遍，`n-1` 轮内收敛、提前退出 |
| SPFA | 只把松弛成功的点入队，队列空即收敛，和 Bellman-Ford 对比 |
| Floyd | 4×4 距离表、三重循环以 k 为中转、`min` 更新逐格可见 |
| Kruskal | 边排序、并查集 `find` / 路径压缩 / 按大小合并、MST 逐条变绿 |
| Prim | 每次选 key 最小的点进树，`key` 是到生成树的最短边 |
| Tarjan 强连通 | `dfn / low`、栈、按分量给节点上色 |
| 网络流 | BFS 找增广路、瓶颈、边上实时显示 `流量 / 容量`、累计最大流 |

## 学习辅助

底部第二行工具条：

| 功能 | 说明 |
|---|---|
| **进度记忆** | 用 `localStorage` 记住每个课时看到第几步，下次打开自动回到原位；侧栏打勾表示已完成 |
| **标记完成** | 手动把一个课时标成已完成，右下角显示总体进度 `已完成 3 / 20` |
| **跳到下一次** | 下拉选事件（交换 / 访问 / 出堆 / 弹栈…），一键跳到下一次发生的位置 |
| **练一练** | 一次三题：**预测下一步** + **结果预测**（跑完答案是多少）+ **概念题**（复杂度/前提/易错点）。答完计分，最好成绩记在课时上（鼠标悬停侧栏可见） |
| **复杂度** | 排序课时会实跑 n = 10…160 画比较/交换曲线；图论课时画 DFS / BFS / Dijkstra / Kruskal 的实跑步数，外加 Floyd 的 n³ 理论线 |
| **并排对比** | 两种模式：**排序**（冒泡/快排/归并任选两个，同一组 16 个数）和**图遍历**（DFS vs BFS，同一张随机图）；两边柱状图/图、计数、解说并排，谁先完成一目了然 |

另外两个交互：

- **点代码某一行** → 跳到这一行第一次执行的步骤
- **点某根柱子** → 弹出这个元素的「值历史」：它被交换过几次、每一步变成了什么（点条目可以直接跳过去）

## 代码诊所

右上角「代码诊所」打开一个独立面板：左边粘贴题面（Markdown），右边粘贴你写的 C++，点「检查」做一遍**离线常见坑扫描**。

从题面里自动识别：

- 数据范围（`n ≤ 10^5`、`10^{18}` 这类写法）
- 时间限制

检查项：

| 类型 | 例子 |
|---|---|
| 错误 | 花括号不配对、数组开小、`memset` 用在 `vector` 上 |
| 警告 | 答案用 `int` 但数据到 1e9、`(l+r)/2` 溢出、`%d` 读 `long long`、疑似 O(n²)、变长数组 |
| 提示 | `cin/cout` 没关同步、循环里用 `endl`、递归深度、多组数据没清空、下标从 1 开始但数组只开了 n |

扫完点「复制给 AI」，会把**题面 + 代码 + 自查结果**打包成一段结构化提问，粘到 DeepSeek 里就能得到逐行批改——逻辑错误还是得靠这一步，静态规则抓不到。

> 注意：这里做的是启发式检查，不是编译器。它不保证不漏、也不保证不误报，定位是「先挡住新手常见坑」。

## 加一个新算法

1. 在文件末尾的 `LESSONS` 里加一条：

```js
{ id: "seg", nav: "线段树", sec: "进阶", view: "array", kind: "seg", code: CODE_SEG }
```

`view` 决定中间面板画什么：`"graph"` 画图，`"array"` 画柱状图，`"dp"` 画二维表格。`sec` 是左侧目录的分组名。

2. 写一个 `simSegTree(g, arr)`，返回 `steps` 数组，每一步是：

```js
{ line: 高亮的代码行号（从 0 开始）, note: "这一句在干什么", events: [ ... ] }
```

3. `events` 就是渲染器认识的全部语言，见 `applyEvents()`：

```
n  edge  adjPush  matSet  fsNew  fsNxt  fsHead
visit  enter  iter  exit  qpush  qpop  dist  cur  hi
settle  hp  hpPop  stat
dsuInit  setParent  setSize  curEdge  mstAdd  kruSkip
arrInit  target  cmp  swap  sorted  window  ptr  pivot  found  rpush  rpop  clear
auxInit  auxSet  auxMark  setMain  query
gridInit  cell  focus  deps  dpClear
deg  spush  spop  ans
hinit  hpush  hswap  hcur  callPush  callPop
```

前两组是图形视图，最后一组是数组视图。渲染器只认事件，所以**加算法不用动播放器**。
以后把轨迹换成 g++ 编译 + gdb 抓取，前端也一行不用改。

## 当前限制与下一步

- 轨迹目前由 JS 模拟器生成（保证与展示的 C++ 逻辑一致），还不能直接跑**你自己写的** C++。
  下一步：服务端 `g++` + `gdb` 单步，或 clang 插桩，产出同样的事件流。
- 图与数组规模建议 ≤ 10~12 个元素，再大标签会拥挤。
- 未做移动端专项适配，窄屏会纵向堆叠。
- 计划中的功能：线段树 / 树状数组 / KMP / 区间 DP / 网格连通块 / 强连通分量。
